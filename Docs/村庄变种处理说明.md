# 村庄变种处理说明

## 问题

原版 Minecraft `/locate` 对村庄的处理：
```
/locate village
```
游戏内部会识别 **5 种村庄变种**：
1. `village_plains` - 平原村庄
2. `village_desert` - 沙漠村庄
3. `village_savanna` - 热带草原村庄
4. `village_taiga` - 针叶林村庄
5. `village_snowy` - 雪原村庄

每种变种内部还有 **旋转 + 尺寸变化**（由 `chunkGenerateRnd` 决定）：
- 平原：8 种配置（sx×sz 从 7×7 到 22×18）
- 沙漠：6 种配置
- 热带草原：8 种配置
- 针叶林：4 种配置
- 雪原：6 种配置

---

## 当前实现

### 策略 1：种子推演（有种子）

**代码**：`structure_map.enumerate_structures(seed, version, viewport, struct_keys=("village",))`

**处理**：
- 输入 `struct_keys=("village",)` → 匹配所有村庄变种
- 遍历 5 种村庄群系（`_check_village`）
- 对每个变种调用 `_village_variant()` 计算旋转和尺寸
- 群系校验通过后返回**统一类型**：`"struct": "village"`
- 坐标：区域锚点（cubiomes 算法）

**优点**：
- 自动覆盖所有变种
- 返回统一的 `"village"` 类型
- 精确定位（基于种子的生成算法）

**输出**：
```python
{"struct": "village", "name": "村庄", "x": 1234, "z": -567, "biome": 1}
```

---

### 策略 2：解析 NBT（无种子）

**代码**：从 chunk NBT 提取 `structures.starts.<类型>.Children[].BB`

**实际 NBT 中的类型名称**（Minecraft Wiki + 实测）：

| NBT 中的类型键 | 对应变种 | 示例坐标 |
|---------------|---------|---------|
| `minecraft:village` | 通用键（所有变种共用） | `starts.minecraft:village.Children[0].BB` |
| `village` | 简写键 | `starts.village.Children[0].BB` |

**关键发现**：
- **Java 版 1.18+ chunk NBT 中，所有村庄变种统一存储为 `village`**
- 变种信息**不在 NBT 结构类型字段中**
- 变种信息可能存储在：
  - `Children[].Name` 字段（如 `"minecraft:village/plains"`）
  - 或从方块/群系反推

**当前解析逻辑**：
```python
for st_type, data in starts.items():
    if st_type != struct_type:  # 用户输入的 "village"
        continue
    # st_type 可能是 "minecraft:village" 或 "village"
```

**问题**：
- 用户输入 `village` → 代码匹配 `st_type == "village"`
- 但 NBT 中实际是 `"minecraft:village"`（带命名空间）
- **匹配失败 → 找不到结构**

---

## 解决方案

### 方案 1：宽松匹配（推荐）

**修改**：匹配时忽略 `minecraft:` 前缀

```python
# 用户输入：village
# NBT 实际：minecraft:village
normalized_input = struct_type.lower()
normalized_nbt = st_type.lower().replace("minecraft:", "")

if normalized_input != normalized_nbt:
    continue
```

**优点**：
- 用户只需输入 `village`
- 自动匹配 `minecraft:village` / `village`
- 向后兼容

---

### 方案 2：支持变种查询（可选扩展）

**需求**：用户能否输入 `locate village_plains` 只找平原村庄？

**实现**：
```python
# 用户输入：village_plains
if struct_type.startswith("village_"):
    variant = struct_type.replace("village_", "")
    # 从 Children[].Name 提取变种（如果 NBT 存储了）
    child_name = child.get("Name", "")
    if f"village/{variant}" in child_name:
        # 匹配成功
```

**限制**：
- 需要确认 NBT 是否存储了变种信息（`Children[].Name` 字段）
- 如果未存储，无法区分变种

---

### 方案 3：从群系推断变种（高级）

**思路**：找到村庄锚点后，读取该位置的群系 → 推断变种

```python
from Utils.MapPreviewer.biome_noise import BiomeSampler

sampler = BiomeSampler(seed, version_key)
biome_id = sampler.biome_at(x >> 4, 319 >> 2, z >> 4)

variant_map = {
    1: "village_plains",      # PLAINS
    2: "village_desert",      # DESERT
    35: "village_savanna",    # SAVANNA
    5: "village_taiga",       # TAIGA
    12: "village_snowy",      # SNOWY_PLAINS
}
variant = variant_map.get(biome_id, "village_unknown")
```

**优点**：
- 可区分变种
- 精确到变种级别

**缺点**：
- 需要种子（无种子模式无法群系采样）
- 额外计算开销
